# Моушн-видео по детским рисункам

`drawings_motion.mp4` — 1920×1080, 30 fps, 33,5 с.

Сюжет:
1. **Лист 1** — рисунки «прорисовываются» маркером слева направо, затем оживают:
   человечки шагают, стрелки толкаются вправо, фигурка наверху прыгает,
   завитки качаются, а по красной верёвке в серое ведро стекают капли нефти, и оно наполняется.
2. Перелистывание страницы.
3. **Лист 2** — прорисовка, затем фигурки слева танцуют, маленький человечек подпрыгивает,
   большая фигура справа покачивается, как лодка. В конце — затухание.

## Как пересобрать

```bash
pip install opencv-python-headless scikit-image numpy
cd motion/src
python3 seg.py                         # выделение красного и серого маркера с фото
python3 render.py ../drawings_motion.mp4
```

Нужен `ffmpeg` в PATH. Исходные фото листов: `src/sheet1.webp`, `src/sheet2.webp`.
