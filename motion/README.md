# Мультфильм по рисункам: история про Годзиллу

**`godzilla.mp4`**: 1920×1080, 30 кадров в секунду, 54 с, со звуком.

Сюжет (как его рассказал автор рисунков):
1. Годзилла идёт, натыкается на город и разрушает его.
2. Идёт дальше, снова натыкается на дома и разрушает их атомным дыханием.
3. Годзилла нападает на Конга и побеждает его.
4. Идёт дальше, и на него нападает Сцилла. Они борются, и Годзилла побеждает атомным дыханием.

Рисунки взяты прямо с фотографий листов: линии маркера вырезаются и анимируются.
Эффекты (атомное дыхание, взрывы, обломки, пыль, надписи «БАХ!») и звук генерируются кодом.

`drawings_motion.mp4`: первая, бессюжетная версия.

## Как пересобрать

```bash
pip install opencv-python-headless scikit-image numpy pillow
cd motion/src
python3 seg.py                          # выделение красного и серого маркера с фото
python3 story.py ../godzilla.mp4        # мультфильм со звуком
python3 story.py x.mp4 400 1380         # только пробные кадры -> prev_XXXX.jpg
```

Нужен `ffmpeg`. Шрифты Caveat и Rubik Mono One распространяются по лицензии SIL Open Font License.
