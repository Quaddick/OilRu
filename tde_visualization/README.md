# Приливное разрушение звезды чёрной дырой — 30 с, 4K

Кинематографичная научная визуализация, полностью процедурная: собственная
симуляция частиц + собственный CPU-рендерер (numba). Никаких внешних 3D-пакетов.

Готовый ролик: `tde_4k.mp4` (3840×2160, 30 fps, 30 с, H.264).

## Физический сценарий

| Параметр | Значение |
|---|---|
| Чёрная дыра | M = 5·10⁵ M☉, R_s = 2GM/c² ≈ 1,48·10⁶ км ≈ 2,1 R☉ |
| Тень (критический прицельный параметр) | b_c = 3√3/2 · R_s ≈ 2,6 R_s |
| Звезда | субгигант, 1,3 M☉, R* = 6 R☉ ≈ 2,85 R_s |
| Соотношение | диаметр звезды ≈ 2,9 × диаметра горизонта, масса в ≈ 4·10⁵ раз меньше |
| Приливный радиус | r_t = R*(M/M*)^{1/3} ≈ 440 R☉ ≈ 200 R_s ≫ R_s |
| Перицентр | r_p = 12 R_s > r_ISCO = 3 R_s > R_s |

Звезда разрушается далеко за пределами горизонта; горизонт пересекает лишь ничтожная
доля вещества уже из диска.

**Художественные упрощения (честно):**
* время сжато нелинейно (минуты пролёта перицентра — месяцы формирования диска),
  см. `timeline.py`;
* пространственный масштаб орбит обломков сжат: разброс энергий вычислен с
  эффективным отношением масс q_eff ≈ 120 вместо 4·10⁵, чтобы возвращающиеся потоки
  уместились в кадр. Размеры звезды, горизонта, тени и перицентра — в истинных пропорциях.

## Что посчитано, а не нарисовано

* **Орбиты** — потенциал Пачинского–Виты (даёт релятивистскую прецессию перицентра,
  из‑за которой поток пересекает сам себя).
* **Приливное растяжение** — каждый слой звезды удерживается силой, пропорциональной
  локальной самогравитации (политропа n = 3); рыхлые внешние слои деформируются и
  срываются первыми через точки L1/L2, плотное ядро — последним (перекрывающееся
  движение из физики, а не из ключей). Потеря оболочки ослабляет связь ядра.
* **Энергетический спектр** — после освобождения элементы баллистические: ≈ 51 %
  массы связано и возвращается по вытянутым орбитам, ≈ 49 % уходит.
* **Столкновение потоков** — неупругие ударные волны на 3D-сетке: кинетическая
  энергия пересекающихся потоков переходит в тепло → свечение и цвет (температура
  чёрного тела). Пик яркости ≈ 20–21,5 с.
* **Формирование диска** — диссипация радиального движения при сохранении момента
  импульса → газ оседает на радиусе циркуляризации ≈ 2r_p.
* **Линзирование** — фоновые звёзды и газ: точечная линза (два изображения,
  усиление); тонкий диск: трассировка геодезических Шварцшильда (арка дальней
  стороны над тенью, фотонное кольцо), доплеровское усиление и гравитационное
  красное смещение g = 1/(1+z).
* **Тень** — ничего из-за дыры не видно внутри b_c.

## Запуск

```bash
pip install numpy numba opencv-python-headless scipy
python3 simulate.py snap            # ~2 мин, 220 тыс. частиц, 900 снимков
python3 render_frames.py snap out --width 3840 --video --workers 4
ffmpeg -f concat -safe 0 -i out/list.txt -c copy tde_4k.mp4
```

Файлы: `params.py` (физика), `timeline.py` (сжатие времени), `simulate.py`,
`camera.py` (хореография камеры), `render.py`, `disk_trace.py`, `colour.py`.
