# Установка LAMPA и TorrServe на Android TV одной командой

Скрипты ставят на телевизор два приложения по локальной сети через ADB, без ручного
копирования APK на флешку и без файловых менеджеров:

| Приложение | Пакет | Источник |
|---|---|---|
| LAMPA | `top.rootu.lampa` | [github.com/lampa-app/LAMPA](https://github.com/lampa-app/LAMPA/releases) |
| TorrServe (MatriX, клиент для Android) | `ru.yourok.torrserve` | [github.com/YouROK/TorrServe](https://github.com/YouROK/TorrServe/releases) |

Версия не зашита в скрипт — при каждом запуске берётся **последний релиз** с GitHub.

## Что скрипт делает сам

1. Находит `adb`, а если его нет — скачивает официальные Android platform-tools с `dl.google.com`.
2. Сканирует твою подсеть `/24` и находит устройство с открытым ADB-портом 5555.
3. Подключается и ждёт, пока ты подтвердишь отладку на телевизоре.
4. Скачивает свежие APK и ставит их (`adb install -r -g`).
5. Проверяет через `pm list packages`, что пакеты реально появились на ТВ.

## Перед запуском — один раз на телевизоре

1. **Настройки → Об устройстве → Сборка** — нажать 7 раз, включится режим разработчика.
   (Судя по твоему сообщению, этот шаг уже сделан.)
2. **Настройки → Для разработчиков** — включить **«Отладка по USB»**. На большинстве
   Android TV этим же переключателем открывается сетевой ADB на порту 5555.
   Если есть отдельный пункт **«Отладка по сети» / «Отладка по Wi-Fi»** — включить его.
3. Телевизор и компьютер должны быть в одной сети Wi-Fi/LAN.

## Запуск

**Linux / macOS:**

```bash
bash install-tv-apps.sh                      # найдёт телевизор сам
bash install-tv-apps.sh --tv 192.168.1.50    # если знаешь IP телевизора
```

**Windows (PowerShell):**

```powershell
powershell -ExecutionPolicy Bypass -File install-tv-apps.ps1
powershell -ExecutionPolicy Bypass -File install-tv-apps.ps1 -TvIp 192.168.1.50
```

Во время работы на экране телевизора появится запрос **«Разрешить отладку по сети?»** —
нажми «Разрешить» (лучше с галочкой «Всегда разрешать с этого компьютера»). Скрипт ждёт
этого до 90 секунд.

IP телевизора, если нужен вручную: **Настройки → Сеть и интернет → твоя сеть → IP-адрес**.

## Android 11+ / Google TV: сопряжение по коду

На новых прошивках прямое подключение к 5555 закрыто, нужен режим с одноразовым кодом.
На ТВ: **Для разработчиков → Отладка по Wi-Fi → Подключить с помощью кода сопряжения** —
там будут адрес, порт и шестизначный код. Затем:

```bash
bash install-tv-apps.sh --pair 192.168.1.50:41234 123456
```

```powershell
powershell -ExecutionPolicy Bypass -File install-tv-apps.ps1 -PairAddr 192.168.1.50:41234 -PairCode 123456
```

Порт сопряжения (`41234`) — временный и меняется каждый раз, порт подключения — другой.
Код действует один раз.

## После установки

TorrServe — это торрент-движок, LAMPA — оболочка, которая его использует. Связать:

1. Запустить **TorrServe** на телевизоре — он поднимет локальный сервер на `127.0.0.1:8090`.
   В настройках TorrServe включить автозапуск, чтобы не запускать вручную каждый раз.
2. В **LAMPA**: Настройки → Торренты → выбрать TorrServe, адрес `http://127.0.0.1:8090`.

## Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| «Устройство с открытым ADB не найдено» | Отладка не включена, ТВ в другой сети (например, 5 ГГц гостевой), или прошивка требует сопряжения по коду — см. раздел выше. Попробуй с явным `--tv <IP>`. |
| Состояние зависло на `unauthorized` | Запрос на ТВ не подтверждён. Иногда окно прячется за текущим приложением — сверни его кнопкой Home. |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | На ТВ уже стоит сборка с другой подписью. Удалить: `adb -s <IP>:5555 uninstall top.rootu.lampa` и запустить скрипт заново. |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | Скачался APK не под процессор телевизора. Скрипт выбирает universal/arm64, но если релиз разделён иначе — скачай нужный APK вручную и поставь `adb install -r <файл>`. |
| Скрипт нашёл несколько устройств | В сети есть другие Android-устройства с ADB. Перезапусти с явным `--tv <IP телевизора>`. |

## Замечание о проверке

Скрипт для Linux/macOS протестирован здесь частично: синтаксис, разбор ответа GitHub API и
сканирование сети проверены на живом слушателе (находит хост за ~4 секунды на `/24`).
Шаги, требующие реального телевизора — `adb connect`, подтверждение отладки и сама
установка — воспроизвести в изолированном окружении невозможно, они не проверены запуском.
PowerShell-версия не запускалась вообще: в окружении нет PowerShell.
